## Adding one

Check the licence text itself, not a summary of it: it must allow redistribution of the ROM. Add the file as released, a row here with where it came from and its checksum, and its notice to `LICENSES.txt`. No commercial ROMs, and nothing whose author has asked for it not to be used this way.
